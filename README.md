## Run the website on your computer

1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click `index.html` to open it in a browser.
4. For a better development workflow, open the folder in Visual Studio Code and use the Live Server extension.

No build process or package installation is required.

## Important: personalize before publishing

3. Check every project description and edit it so it accurately describes your own contribution.

Copy your LAN photograph and PC setup photograph into `assets/`, for example:

The current website uses designed visual panels for these two areas. If you want to use the photos, add an `<img>` element inside the `.lan-panel` and `.setup-panel` sections in `index.html`, then style it in `style.css`.

## Publish with GitHub Pages (beginner guide)

### A. Create a GitHub account
1. Visit https://github.com/
2. Select **Sign up** and create an account.
3. Verify your email address and sign in.

### B. Create a repository
1. Click the **+** icon in the top-right corner and choose **New repository**.
2. Enter a repository name such as `oishi-gain-portfolio`.
3. Choose **Public**.
4. Select **Create repository**.

### C. Upload your website files
1. Open the new repository.
2. Choose **Add file → Upload files**.
3. Open the extracted portfolio folder on your computer.
4. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the complete `assets` folder (including the profile image).
5. Scroll down and select **Commit changes**.

Important: `index.html` must be in the repository's top-level/root folder, not inside another nested folder.

### D. Turn on GitHub Pages
1. In the repository, open **Settings**.
2. Select **Pages** from the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**.
5. Click **Save**.
6. Wait a few minutes. Refresh the Pages settings page; GitHub will show the public website address.
7. Open the address in a new browser tab and test the site.

Your link will usually look like:
`https://YOUR-GITHUB-USERNAME.github.io/oishi-gain-portfolio/`

The exact URL depends on your GitHub username and repository name.

### E. Updating the website later
Edit the files on your computer, then open the GitHub repository and upload the changed files again, or use GitHub's web editor. Commit the changes. GitHub Pages will publish the update.

## Alternative: Netlify (drag-and-drop)
1. Visit https://www.netlify.com/ and sign in.
2. Open the Netlify dashboard.
3. Choose **Add new site** or the manual deploy/drag-and-drop option.
4. Drag the extracted project folder (the folder containing `index.html`) into the deploy area.
5. Wait for deployment and open the generated public URL.
6. You can change the site name in the site settings if the name is available.

## Google Drive ZIP submission
1. Upload the original ZIP file to Google Drive.
2. Right-click the ZIP and choose **Share**.
3. Under General access, change **Restricted** to **Anyone with the link**.
4. Set permission to **Viewer**.
5. Click **Copy link** and submit that link where your teacher asks for the source-code ZIP.
