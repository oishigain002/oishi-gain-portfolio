## Run locally
1. Extract the ZIP.
2. Open the project folder.
3. Double-click `index.html`, or open the folder in VS Code and use Live Server.

## Edit the website
- Text, sections, email and links: `index.html`
- Colors, layout, spacing and responsive design: `style.css`
- Mobile navigation and dynamic year: `script.js`
- Images: replace the files inside `assets/` while keeping the same filenames, or update the image `src` paths in `index.html`.

## Deploy with GitHub Pages
1. Open the GitHub repository `oishi-gain-portfolio`.
2. Remove any old nested folder named `251-35-558_44G1_OishiGain` if one exists and is not wanted.
3. Upload the **contents** of this project folder to the repository root. The `index.html` file must appear directly on the repository's main Code page, alongside `style.css`, `script.js`, `README.md`, and the `assets` folder.
4. Commit the upload to the `main` branch.
5. Open Settings → Pages. Select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
6. Wait for GitHub Pages to finish deploying. The expected site address is `https://oishigain002.github.io/oishi-gain-portfolio/`.

## Update later directly on GitHub
Open a file in the repository, click the pencil (Edit) icon, make the change, then click **Commit changes**. For image changes, open `assets`, choose Add file → Upload files, upload the replacement image with the same filename, and commit.
